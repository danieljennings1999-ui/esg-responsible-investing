# Can Investors Go Green Without Giving Up Returns?

## Overview
An empirical analysis of environmental screening, financial performance 
and climate risk in US equity markets.

**Author:** Daniel Jennings  
**Date:** September 2026  
**Tools:** Python, PyPortfolioOpt, Refinitiv (LSEG), yfinance, Matplotlib

## Key Findings
- No financial penalty for environmental screening
- Green portfolio returned 21.1% vs Brown 24.7% vs Market 20.3%
- Simpson's Paradox discovered in ESG-return relationship
- Green portfolio emissions score 74.5 vs Brown 31.8
